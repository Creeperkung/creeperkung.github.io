# Relic Index

A searchable index of every Arknights Integrated Strategies relic, covering all EN themes. You can filter by theme, rarity and type (cursed/secret), and search names, effects and descriptions.

```bash
cd web
npm install
npm run dev
```

Relic data comes from [ArknightsGameData_YoStar](https://github.com/Kengxxiao/ArknightsGameData_YoStar). To refresh it after a game update, run `node scripts/build-relics.mjs` in `web/`.
